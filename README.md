# HALO

Round-watch messenger for answering SMS, MMS, and RCS without taking the phone out.

The watch is the app. The handset view is a mirror of the same threads, so a reply sent from the wrist shows up on the phone.

- RCS threads support suggested replies, typing, reactions, read receipts, and photos.
- SMS-only threads still take a direct reply. Text sends as SMS. Photos and voice notes fall back to MMS.

```bash
npm install
npm run dev
```

This preview uses sample threads. It does not connect to a carrier or a physical watch.
The color dot on the watch face switches the accent. UP and DOWN preview a look. START keeps it.
